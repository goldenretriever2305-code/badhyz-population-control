# Optimal Control and Numerical Simulation of Gazelle and Wolf Population Dynamics in Badhyz Nature Reserve

This repository contains the Python implementation of the Boundary Value Shooting Algorithm with Fourth-Order Runge-Kutta (BVSA-RK4) used to model and simulate optimal harvesting control strategies.

## Requirements
* Python 3.x
* numpy
* matplotlib

## Running the Code
Run the main script to reproduce the numerical trajectory data and save Figures 1 and 2:
```bash
python main_simulation.py
